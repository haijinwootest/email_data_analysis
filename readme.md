## 1. 프로젝트 한 줄 소개

이메일을 받은 고객의 구매 성과를 단순 집계하는 대신, **이메일 미발송 대조군과 비교하여 캠페인이 추가로 만들어낸 전환과 매출을 검증**한 프로젝트입니다.

Python 기반 데이터 분석과 통계 검정을 AI의 지원으로 수행했으며, 분석 결과를 그대로 수용하지 않고 독립 재계산, 통계 검정 보완, 데이터 무결성 확인을 거쳐 최종 결과를 정리했습니다.

### 핵심 분석 결과

| 분석 질문 | 주요 결과 | 95% 신뢰구간 |
|---|---:|---|
| Q1. 이메일 발송의 증분 전환 효과 | **+0.4955pp** | +0.3508 ~ +0.6333pp |
| Q2. 이메일 유형 간 전환율 차이 | **+0.3694pp** | +0.1746 ~ +0.5663pp |
| Q3. 고객당 증분 매출 | **+$0.5968** | +$0.3713 ~ +$0.8093 |

> 위 수치는 과거 특정 실험에서 관측된 집단 간 차이입니다. 증분 매출을 순이익이나 ROI로 해석할 수는 없습니다.

## 2. 프로젝트 배경 및 문제 정의

일반적인 마케팅 성과 분석에서는 이메일 발송 이후 구매한 고객 수와 매출을 확인합니다.

하지만 이메일을 받은 고객의 구매가 모두 이메일 캠페인 때문에 발생했다고 볼 수는 없습니다. 이메일을 받지 않았더라도 구매했을 고객이 존재할 수 있기 때문입니다.

따라서 캠페인의 실제 효과를 평가하려면 단순 성과 집계가 아니라 **미발송 대조군과의 비교를 통한 증분 효과(Incremental Effect)** 분석이 필요합니다.

이번 프로젝트의 핵심 문제는 다음과 같습니다.

**"이메일을 발송했을 때, 발송하지 않았을 경우보다 실제로 얼마나 많은 구매와 매출이 추가로 발생했는가?"**

이를 통해 마케팅 성과를 보다 타당한 기준으로 평가하고, 향후 캠페인 운영에 활용할 수 있는 근거를 마련하고자 했습니다.

### 전처리 원칙

이번 프로젝트에서는 원본 데이터를 임의로 변경하거나 관측치를 삭제하기보다, **분석 단위와 데이터 무결성을 유지하는 것**을 우선했습니다.

### 실제 처리 내용

**1. 원본 데이터 보존**

`prepare_email_experiment.py`를 사용하여 원본과 동일한 내용을 갖는 `email_experiment_clean.csv`를 생성했습니다.

두 파일의 SHA-256 해시가 일치하는지 확인했습니다.

**2. 동일한 행 유지**

원본 데이터에서 완전히 동일한 행이 6,562건 확인되었습니다.

하지만 고객 고유 ID가 없기 때문에 값이 같다는 사실만으로 동일 고객의 중복 기록이라고 판단할 수 없었습니다.

이에 따라 해당 행들을 임의로 삭제하지 않았습니다.

**3. 실제 0달러 매출 유지**

전체 64,000행 중 63,422행의 `spend` 값이 0이었습니다.

이 값은 결측값이 아니라 구매가 발생하지 않은 고객의 실제 관측 결과이므로 그대로 유지했습니다.

**4. 분석용 파생 변수 생성**

이메일 발송 배정 여부를 나타내는 `email_assigned` 변수를 생성했습니다.

```python

email_assigned = 0  # No E-Mail
```

## 9. 심화 분석 및 검증

### 분석 원칙: ITT

ITT(Intention-to-Treat)는 처음 배정된 전체 고객을 기준으로 효과를 평가하는 방식입니다.

이번 분석에서는 이메일 수신 후 방문했거나 구매한 고객만 선택하지 않고, 각 집단에 배정된 모든 관측 행을 포함했습니다.

이를 통해 구매 여부 등 사후 결과를 기준으로 분석 대상을 임의로 변경하지 않았습니다.

### Q1: 이메일 발송 효과

**비교:** 전체 이메일 발송 배정 집단 vs 미발송 대조군

**방법:**
- 두 독립 비율 차이에 대한 양측 z검정
- Newcombe 방식의 95% 신뢰구간

### Q2: 이메일 유형 차이

**비교:** 남성용 이메일 배정 집단 vs 여성용 이메일 배정 집단

**방법:**
- 두 독립 비율 차이에 대한 양측 z검정
- Newcombe 방식의 95% 신뢰구간

이 결과는 두 이메일 유형 간 직접 비교이며, 고객 성별에 따른 효과 차이를 의미하지 않습니다.

### Q3: 고객당 증분 매출

**비교:** 전체 이메일 발송 배정 집단 vs 미발송 대조군

**방법:**
- 전체 배정 고객의 평균 매출 차이
- 집단별 고객 행 재표집 부트스트랩 2,000회
- 부트스트랩 백분위수 95% 신뢰구간
- 추가 검증을 위한 Welch 검정과 재배정 검정

### 독립 검증

최초 심화 분석 결과와 별도로 `remediate_and_verify.py`를 사용하여 원본 CSV를 다시 집계했습니다.

이 과정에서는 다음 방법을 활용했습니다.

- `csv.DictReader`를 활용한 독립 집계
- `Decimal`을 활용한 매출 금액 검산
- 원본과 마스터 데이터 간 값 비교
- 독립 난수 시드를 사용한 부트스트랩 재실행
- 추가 통계 검정 수행

독립 부트스트랩은 2,000회, 난수 시드 `8675309`로 수행되었습니다.

관련 파일:

### Q1. 이메일 발송의 증분 구매 전환 효과

미발송 대조군과 비교했을 때 구매 전환율과 고객당 평균 매출 모두 양의 차이가 나타났습니다.

따라서 이메일 캠페인의 성과를 평가할 때 단순 발송 후 구매 건수보다 **증분 전환율과 증분 매출**을 사용하는 것이 적절합니다.

### 2. 이메일 유형별 성과를 별도로 관리할 필요가 있음

남성용과 여성용 이메일 배정 집단의 전환 성과에 차이가 확인되었습니다.

이를 근거로 이메일 유형별 KPI를 구분해 모니터링하고, 후속 실험을 통해 콘텐츠·상품 구성의 영향을 추가 검증할 수 있습니다.

단, 이 결과만으로 특정 이메일 유형을 모든 고객에게 적용해야 한다고 결론내릴 수는 없습니다.

### 3. 통계적 효과와 실제 사업적 수익성은 구분해야 함

고객당 증분 매출은 양수였지만 발송 비용과 마진 자료는 제공되지 않았습니다.

따라서 마케팅 예산 확대나 ROI 판단에는 추가 데이터가 필요합니다.

### 운영 제안

- 증분 전환율 및 고객당 증분 매출을 핵심 KPI로 관리

위 항목은 분석 결과에 근거한 **운영 제안**이며, 실제 사업에서 실행·적용된 성과는 확인되지 않았습니다.

**분석 측면**

- 발송 비용 및 상품 마진 확보 후 증분 이익과 ROI 계산
- 후속 무작위 실험으로 결과 재현성 확인
- 개별 고객 ID 및 시간 정보가 포함된 데이터로 장기 성과 분석
- 사전 고객 특성을 활용한 이질적 효과 탐색
- 추가 실험에서 이메일 유형과 고객 특성의 관계 검증

**기술 및 재현성 측면**

- 절대경로를 프로젝트 상대경로로 변경
- `requirements.txt` 또는 `pyproject.toml` 추가
- 분석 단계별 실행 스크립트 통합
- 주요 KPI에 대한 자동 테스트 추가
- GitHub Actions 기반 재현성 검사 구축

위 사항은 **향후 개선 제안**이며, 현재 프로젝트에서 모두 구현된 기능은 아닙니다.

## 18. 프로젝트를 통해 배운 점

이번 프로젝트에서 확인할 수 있었던 중요한 분석 원칙은 다음과 같습니다.

**첫째, 분석 지표는 비즈니스 문제를 정확히 반영해야 합니다.**

이메일 발송 후 구매 건수를 단순 집계하는 것보다, 미발송 대조군과의 차이를 분석하는 것이 캠페인의 증분 효과를 평가하는 데 적합했습니다.

**둘째, 데이터 전처리에서는 삭제나 변환보다 관측 단위와 데이터 의미를 먼저 확인해야 합니다.**

고객 ID가 없는 데이터에서 동일한 행을 무조건 삭제하거나, 구매가 발생하지 않은 0달러 매출을 제외하면 분석 목적이 달라질 수 있습니다.

**셋째, 통계 분석 결과에는 효과 크기뿐 아니라 불확실성과 검정 가정이 함께 제시되어야 합니다.**

증분 전환율과 증분 매출을 신뢰구간 및 추가 검정과 함께 검토함으로써 결과를 보다 신중하게 해석할 수 있었습니다.

**넷째, AI 지원 분석에서도 결과 검증은 별도의 중요한 과정입니다.**

최초 결과에 대한 독립 집계, 검정 방식 보완, 민감도 분석의 해석 구분을 통해 결과의 신뢰성을 높이는 절차를 경험했습니다.

**다섯째, 통계적으로 유의한 결과와 실제 사업적 의사결정은 구분해야 합니다.**

전환율과 매출 차이가 확인되더라도 비용·마진·재현성이 확인되지 않은 상태에서 캠페인 확대를 확정하는 것은 적절하지 않습니다.
